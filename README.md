# family-hub (public)

Public family errands that carry no personal data, served on GitHub Pages.
Anything naming a person, their school, documents or errands lives in the
private twin `markkennethbadilla/private-family-hub`.

### House
- **`house/cat-chicken-care/`**: daily cat and chicken feeding checklist by
  time of day. Self-contained `index.html` on Pages; checkboxes persist in the
  browser and reset each morning.

## Adding a new errand
1. Has personal data (names, documents, school, addresses)? Put it in
   private-family-hub instead.
2. Else create `<person>/<short-slug>/`, add output, add a line above.
